# Demo Plan

## Goal

Demonstrate the full value loop in under a few minutes.

## Narrative

1. **Problem:** renewable energy is about to be curtailed/constrained.
2. **Prediction:** the AI identifies an upcoming waste window before it happens.
3. **Action:** the system recommends moving EV charging into that window.
4. **Outcome:** the Impact page quantifies recovered clean energy and the resulting benefit.

## Demo checklist

- One known-good data scenario is available.
- Dashboard loads without manual repair.
- Forecast visibly shows an upcoming opportunity.
- Charging translates MWh into an understandable EV outcome.
- Impact metrics are consistent with the input scenario.
- Simulated vs real values are clearly labelled.
- No API keys appear on screen.
- A backup screenshot/video exists for each critical screen.

## Freeze rule

Near judging time, prioritise demo stability over adding non-essential features.
